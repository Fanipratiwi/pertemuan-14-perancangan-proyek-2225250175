## Deskripsi
Proyek ini merupakan rancangan program Python untuk
membantu guru merekap dan menganalisis nilai matematika siswa.

## Tujuan
- Mempermudah rekap nilai siswa.
- Menghitung rata-rata nilai.
- Menentukan nilai tertinggi dan terendah.
- Merancang pengujian program.

## Teknologi
- Python
- Visual Studio Code
- Git
- GitHub

## Struktur Folder
- latihan/: latihan perancangan proyek.
- tugas/: proposal proyek.
- src/: rancangan kode program.
- data/: tempat penyimpanan data.
- tests/: tempat test case.
- docs/: dokumentasi proyek.

## Tahapan Pengerjaan
1. Menentukan masalah.
2. Menyusun proposal.
3. Merancang algoritma.
4. Menentukan struktur program.
5. Menyusun test case.
6. Menyiapkan repository GitHub.

## Pengujian
Pengujian direncanakan untuk input normal,
nilai batas, input tidak valid, dan data kosong.
